# GameTrade

Маркетплейс игровых аккаунтов, буста и услуг (в стиле GGSel).

**Цветовая схема:** красно-фиолетовая (тёмная тема)  
**Комиссия площадки:** 5%  
**Платежи:** ЮMoney, СБП, карты (эскроу)

## Стек

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- React 19

## Запуск

```bash
cd gametrade
npm install
npm run dev
```

Открой http://localhost:3000

## Что уже сделано (MVP)

- Главная страница с hero, категориями, популярными играми и карточками товаров
- Каталог
- Страница товара с кнопкой покупки и блоком гарантии
- Header + Footer
- Красно-фиолетовая тёмная тема
- Моковые данные (8 товаров)

```
  components/

```

## Комиссия

При создании заказа платформа удерживает 5% от суммы. Деньги продавцу переводятся после подтверждения покупателем.
